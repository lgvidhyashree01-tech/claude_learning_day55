How Events Work

1

The Event Loop

JavaScript is single-threaded. The event loop continuously checks the call stack and moves tasks from the callback queue to the stack.

2

Listeners vs Handlers

addEventListener is preferred over onclick as it allows multiple listeners on a single element without overwriting.

3

Event Object (e)

The browser automatically passes an object containing details: target, type, timestamp, and preventDefault().
